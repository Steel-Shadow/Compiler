# 优化文档

优化分为中间代码优化和目标代码优化。中端负责跨基本块的数据流与值优化，MIPS 后端负责寄存器分配、调用约定和目标相关的 peephole。

## 中间代码分析

`src/middle/IRUtils.*` 集中保存与具体优化 Pass 无关的 IR 查询，包括值类型转换、Temp 定义/使用、定义位置表、常量表和环绕整数运算。各 Pass 不再维护这些工具的私有副本。

`src/middle/Analysis.*` 为每个函数构造 CFG，并计算：

- 前驱、后继、支配集合、立即支配节点、支配树和 dominance frontier；
- 支配树深度、自然循环及循环嵌套深度；
- IR Temp 的块级及指令级活跃信息；
- 可寄存器化局部标量的活跃信息。

内存优化另外按“基对象 + 常量字节偏移”区分精确位置，并识别由归纳变量形成的仿射数组下标。动态下标、逃逸地址和未知调用会保守地杀死相关状态，避免把不同数组或可能别名的访问错误合并。

这些分析同时服务于 IR 优化和后端寄存器分配。

## IR 优化

`Module::optimize()` 通过函数级 pass manager 迭代运行以下优化：

1. 常量折叠、代数化简、SCCP、复制传播、布尔条件化简和常量分支折叠。
2. 将满足尾调用形态的自递归改写为参数更新和回边，消除递归栈帧。
3. 使用迭代 dominance frontier 为可提升标量插入 pruned phi，并沿支配树重命名定义和使用，完成 mem2reg。
4. 对精确内存位置执行跨块值转发和覆盖 store 删除；对可证明无别名、无路径写入的稠密数组初始化循环转发仿射数组值。
5. 执行 GVN-GCM，并以 PRE 消除只在部分前驱可用的公共表达式；GCM 根据 operand/use 支配约束和循环深度选择位置。
6. 执行 LICM、归纳变量强度削弱、只读全局折叠和入口常量池化。
7. 对可静态求迭代次数的无副作用循环做归约闭式化或小循环展开；识别整段全局 `char` 数组清零，并降低为批量 `MemZero`。
8. 跟踪模运算值域，删除幂等 `%`，将有界模加法改为条件修正；常量除数和模数在后端使用乘法魔数降低。
9. 构造过程间副作用、外部内存读取、终止性和常量返回摘要；据此删除无用调用、合并纯调用，并进行受限内联和常量实参特化。
10. 基于变量活跃性删除死 store，基于 use-def chain 删除未使用的纯计算，并清理退化 phi、空内存对象和不可达块/函数。

优化后的 `ir.txt` 保留 SSA phi 以便检查。进入后端前，phi 在 CFG 边上降低为并行复制；多后继前驱会拆分关键边，复制环使用额外 Temp 打破。

GCM 只移动不会异常且没有副作用的纯计算。`div/mod` 可以在支配范围内参与 GVN，但不会被投机移动；内存访问由独立的保守数据流处理，不混入 value GVN。

当前实现没有为所有内存定义显式建立 Memory SSA 节点，而是采用按位置的数据流状态和路径 clobber 检查。这覆盖了本项目收益明显的数组模式，同时避免引入完整 Memory SSA 的工程量。

### 常量计算

数组常量下标在 IR 生成时直接计算；普通表达式中的常量继续由优化 pass 传播和折叠。`char` 结果按 8 位无符号值归一化。

## 寄存器分配

### 临时寄存器分配

后端在 Temp 活跃性分析结果上建立冲突图，通过简化、选择和溢出启发式进行图着色：

- `$t0-$t6` 保存全函数范围的着色 Temp；
- `$t7-$t9` 构成每条指令独立重置的 scratch 池，用于读取溢出操作数和写回结果；
- 着色失败的 Temp 在函数生成前预留栈槽；
- 溢出的常量使用 `li` 重新物化，不写入栈内存。
- 着色器比较普通溢出与“全部常量重新物化”两种方案的估算代价，避免为了保留低成本常量而溢出热计算值。

move 的源和目的在构图时允许合并颜色，后续 peephole 还能删除因此产生的自复制。
SSA 参数值会预着色到 `$a0-$a3`，并在无冲突时沿 phi 边复制继续合并，避免入口和循环回边上的多余 move。

### 全局寄存器分配

局部标量变量使用独立的活跃性和冲突图，着色到 `$s0-$s7`。数组、全局变量、取地址对象及其他不安全候选仍保存在内存中。

寄存器遵循 MIPS 调用规范：

- `$t0-$t6` 由调用者保存，但仅保存调用点之后仍活跃的颜色；
- `$s0-$s7` 由实际使用它们的被调函数保存和恢复；
- 非叶函数保存 `$ra`，叶函数省略该访存；
- 至多四个参数的叶函数在所有调用点均可安全直传时使用 `$a0-$a3`，包括数组地址参数；其余函数统一通过栈传参；
- 同一函数不会混用两种参数约定，形参在冲突图中按并行输入处理，返回值使用 `$v0`。

最终 peephole 会检查每个函数实际留下的 `$s0-$s7` 使用，删除因前序优化变成空操作的 callee-saved 保存/恢复往返。

`$fp` 保留为地址计算 scratch，不参与图着色。`$at`、`$k0-$k1` 等保留寄存器不参与分配。

## MIPS Peephole

部分 MIPS 指令支持立即数直接参与计算，无需提前加载到寄存器：

```text
li   $t1 1
addu $t2 $t0 $t1
------------------
addiu $t2 $t0 1
```

后端还执行以下局部优化：

- 合并 `li`/`move` 与相邻算术指令；
- 将只供分支使用的比较直接选择为 MIPS 比较分支；
- 将乘以 2 的幂改为移位，并用带符号修正的移位实现除以 2 的幂；
- 对非零常量除数/模数使用移位或带符号修正的乘法魔数序列，避免热循环中的硬件 `div`；
- 将整段全局 `char` 数组清零降低为一次展开 128 字节的 word-store 循环和短尾部；
- 删除 `move r, r` 和 `addiu r, r, 0`；
- 删除跳到紧随标签的分支；
- 将“条件分支到下一块 + 无条件跳转”反转为单条条件分支。

对严格匹配的有界双参数尾递推，后端还会执行目标相关的专门降低：用 `clz/ctz` 批量处理连续折半，使用带状态编码的有界直接索引缓存，并在唯一热调用点内联递推函数。该变换要求无副作用、单一热调用点、仿射累加更新、不可变全局上界等条件全部成立；任一条件不满足即不启用。

## 性能验证

优化效果通过新版 Mars 输出的逐例 `FinalCycles` 和总和验证。测试工具、私有题目清单、运行产物及成绩数据统一保存在本地 `test/` 目录，不纳入本仓库；公开文档不记录具体题目或逐例成绩。

## 后续方向

- 更细粒度的参数级 `mod/ref` 摘要和 Memory SSA，可扩大跨调用 memory GVN；
- 循环多出口、复杂归约和非单位步长的通用 ScalarEvolution；
- 基于 profile/块频率的 GCM、代码布局和寄存器溢出代价模型；
- 在设置代码体积预算后扩大循环 CFG 函数内联。

这些方向的边际收益和工程量都高于本轮目标，当前实现保持保守回退路径。
